# 🦍 Tiles Menu

A custom Gorilla Tag-inspired PCVR wrist menu UI prototype.

## Features

- World-space VR menu
- Wrist attachment support
- Purple and dark theme
- Four navigation tabs
- Reusable UI buttons
- Menu visibility toggle
- Desktop testing shortcut

## Version

1.0

## Requirements

- Unity
- C#
- Unity UI (uGUI)
- PCVR-compatible Unity project

## Installation

1. Download or clone this repository.
2. Open your Unity project.
3. Copy the Assets/Scripts folder into your project.
4. Create an empty GameObject named TilesMenuManager.
5. Attach TilesMenu.cs.
6. Assign your wrist anchor.
7. Press Play to test.

## Desktop Testing

Press M to toggle the menu.

## Tabs

- Home
- Visuals
- Settings
- About
